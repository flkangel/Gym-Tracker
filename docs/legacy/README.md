# Legacy v1 notes

These documents describe the v1 prototype (Next.js 16 + Supabase, a unified
daily feed of meals and workouts) that was removed from `main` at the start of
the v2 rewrite. The v1 code is preserved at tag `v1.0.0` and branch `legacy/v1`.

What carries over to v2: the "Glance & Go" UX philosophy from
`PROJECT_CONTEXT.md` (minimal friction, one-handed use, large type, log a set
in one or two taps). What does not: the unified-feed data model and the
WhatsApp integration ideas.
